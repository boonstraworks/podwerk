# Lifespan

Podwerk continues the Podcast Generator 3.2 series. Maintenance releases
(3.2.10, 3.2.11, ...) contain security fixes and keep Podwerk working on
current PHP versions. They are drop-in updates: configuration, data files
and themes stay compatible within the 3.2 series.

| Version                         | Release    | End of Life                |
| ------------------------------- | ---------- | -------------------------- |
| Podwerk 3.2.x                   | 2026       | maintained                 |
| Podcast Generator 3.2.0 - 3.2.9 | 2020-2022  | 2026-04 (project archived) |
| Podcast Generator 3.1           | 2020-05-31 | 2020-05-31                 |
| Podcast Generator 3.0           | 2019-12-31 | 2020-05-31                 |
