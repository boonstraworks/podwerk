# Security

## Supported versions

| Version                           | Supported              |
| --------------------------------- | ---------------------- |
| Podwerk 3.2.x                     | Yes                    |
| Podcast Generator 3.2.9 and older | No: upgrade to Podwerk |

## Report a vulnerability

Please **do not** open a public issue or pull request for a security
problem.

* Preferred: use **Report a vulnerability** on the
  [Security tab](https://github.com/boonstraworks/podwerk/security) of the
  repository (GitHub private vulnerability reporting).
* Or send an e-mail to `info@boonstraworks.nl`.

Describe the problem, the affected version and, if possible, the steps to
reproduce it. You will get an answer within a week. Fixes are released as a
new 3.2.x version; the details are published in the changelog once the fix
is available.
